# FileCanvas 项目入口

所有项目文件已收拢到本文件夹，按开发流程分类。源码、测试、文档、构建输出与发布成品分别存放。

| 文件夹        | 内容                                                                     | 什么时候使用                   |
| ------------- | ------------------------------------------------------------------------ | ------------------------------ |
| `01_源码`     | React 界面、Electron 主进程与 preload、虚拟文件模型、原创图标、HTML 入口 | 开发或修改软件功能             |
| `02_测试`     | 单元测试、真实 Electron 交互测试、开发版与发布版启动检查                 | 验证功能和安全边界             |
| `03_测试结果` | 自动验收 JSON、界面截图、可执行包检查结果                                | 查看最后一次测试证据           |
| `04_构建脚本` | 开发启动、Electron 编译、图标生成脚本                                    | 由 npm 命令调用                |
| `05_项目文档` | 使用与开发说明、阶段一验收报告、目录组织说明                             | 了解使用方式、架构与限制       |
| `06_构建产物` | 自动生成的前端资源与 Electron JavaScript                                 | 构建后运行；不要在这里修改源码 |
| `07_发布成品` | Windows 便携 EXE 与完整运行目录                                          | 直接使用或交付软件             |
| `08_演示体验` | 20 个真实示例文件、清单与演示指南                                        | 亲自体验或录制产品展示         |

`package.json`、锁文件、TypeScript/Vite/Vitest 配置及 Git 配置保留在项目根目录。`node_modules` 是 npm 自动管理的依赖目录；`.git` 保存完整的本地版本历史。

## 直接使用软件

双击 [FileCanvas 0.3.0 Windows 便携版](07_发布成品/FileCanvas-0.3.0-Windows-x64.exe)。画布默认铺满工作区：点击卡片预览正文或文件夹内容，文件栏与 AI 助手按需展开，可进入专注模式。支持模型配置、项目文本索引、内容问答与可撤销的 AI 分类草案。真实移动和恢复仍未开放。

先点欢迎页的示例入口，或 **更多工具 → 体验示例**，自动创建并导入一份 20 文件副本。也可以手动打开 [待整理示例](08_演示体验/待整理示例)。完整操作见 [演示指南](08_演示体验/README.md)。

本次产品定位的依据见 [竞品调研与卖点判断](05_项目文档/产品调研/01_竞品调研与卖点判断.md)，实际修改和验证见 [修改与验证记录](05_项目文档/产品调研/02_修改与验证记录.md)。

## 配置 AI

打开项目后点 **AI 助手 → 配置模型**。可选 OpenAI、DeepSeek、Ollama，地址和模型名可自行编辑，也可选自定义兼容接口。填写自己的密钥后“保存并测试连接”。问答前可建立本地索引，并预览将发送的资料；发送前需勾选确认。

当前正文支持文本和代码；PDF、Office、音视频等未提取正文。索引在本次运行内保留，重启后重建。全电脑知识库的方案和实现边界见 [画布与 AI 改版说明](05_项目文档/画布与AI改版说明.md)。真实模型质量和账户额度仍需配置后验证。

新版构建、42 项单元测试、桌面交互与发布包启动检查结果见 [0.3.0 验收记录](05_项目文档/0.3.0验收记录.md)。若旧版仍在运行，请先关闭旧版再启动新版。

## 继续开发

终端工作目录必须是本文件夹：

```powershell
Set-Location 'D:\ai\a_小红书接单\FileCanvas'
npm.cmd run dev
```

也可双击 [启动开发版.cmd](启动开发版.cmd)。首次复制到其他电脑时先运行 `npm.cmd ci` 安装依赖。

```powershell
npm.cmd test          # 单元测试
npm.cmd run test:e2e  # 构建并执行真实 Electron 交互验收
npm.cmd run test:ai   # 画布与 AI 流程（本机模拟服务）
npm.cmd run build    # 生成 06_构建产物
npm.cmd run package:win # 生成 07_发布成品
```

详细操作见 [使用与开发说明](05_项目文档/使用与开发说明.md)，验证结果见 [阶段一验收报告](05_项目文档/阶段一验收报告.md)。
