# FileCanvas 0.5.0 · Windows 文件整理画布

先在画布中整理，再确认应用到真实文件。支持本地文件与文件夹的移动、重命名、新建分类目录，应用前核对路径，应用后核验，并可恢复最近一次文件移动。

## 下载与使用

到 [Releases](https://github.com/0-qaq-0/FileCanvas/releases/latest) 下载 `FileCanvas-0.5.0-Windows-x64.exe`，双击即可运行，无需安装 Node.js。同一页附有 SHA256 校验值。

- 目前是 Windows x64 免安装版，**未做代码签名**，Windows 可能提示来源。
- 首次建议点击“先用 20 个示例文件试一遍”，示例是程序生成的虚构文件，不会碰你的真实资料。
- 整理自己的资料时，先用少量副本。范围是同一授权本地目录，建议 NTFS，一次最多移动 100 个文件；不支持跨盘、网络共享和符号链接/目录联接。
- 欢迎页的“开始新手教程”约 1 分钟，也可随时从“更多工具”重看。

## 能做什么

1. 打开一个本地文件夹，把文件放到画布上；也可以用平铺、列表、分组三种方式查看同一份整理计划。
2. 拖动归类、改名、新建文件夹，或先让软件出一份分类草案：按文件类型、修改月份、久未修改归档，或用“我的规则”按名称、扩展名、多久没改过、文件大小自定义。卡片会显示待移动、待改名、待新建；摆放卡片只改画布位置。
3. 点击顶部 **检查并应用**，核对原路径、目标路径和结构对照，再点击 **应用到本地文件**。
4. 完成后看到“已应用并核验”。需要放回去时，使用 **恢复上次文件移动**。

`Ctrl+Z` 撤销画布计划；已经应用到磁盘的移动使用专门的恢复入口。外部新增、删除或修改文件后，用 **更多工具 → 刷新并核对**。图标大小、画布背景、对齐网格等在“界面设置”（`Ctrl+,`）里调整。

## 配置 AI（可选）

文件整理不依赖 AI。需要文件解释与位置推荐时，打开 **AI 助手 → 配置模型**，在“常用服务”里选 OpenAI、DeepSeek 或本机 Ollama，也可以填任何兼容接口，然后填入自己的密钥并测试连接。密钥由系统加密保存在本机；首次分析需允许本项目把相关文本发送给你配置的服务。

当前主要读取文本、代码和文件元信息，PDF、Office、音视频尚未提取正文。DeepSeek 官方接口已用程序自己的 AI 代码实测过连接、文件解释和分类方案（2026-10-21）；其他服务的回答质量和费用需要自己核实。

## 从源码运行

需要 Node.js 22.12 或更高的兼容版本，在项目目录打开终端：

```powershell
npm.cmd ci
npm.cmd run dev          # 开发版，使用独立的 %APPDATA%\FileCanvas-Development
npm.cmd run build        # 检查类型并构建运行文件，不生成 EXE
npm.cmd test             # 单元检查
npm.cmd run package:win  # 生成 Windows x64 免安装 EXE（输出到 07_发布成品）
```

桌面交互检查用 Playwright 驱动真实的 Electron 窗口，例如 `npm.cmd run test:smart`、`test:views`、`test:tutorial`、`test:settings`，结果写入 `03_测试结果`。`npm.cmd run test:expanded` 目前需要按自由摆放规则重写，详见 [CHANGELOG](CHANGELOG.md)。

## 项目位置

| 目录          | 内容                                               |
| ------------- | -------------------------------------------------- |
| `01_源码`     | React 界面、Electron 主进程、文件操作与存储、图标  |
| `02_测试`     | 单元测试与桌面交互检查                             |
| `03_测试结果` | 本机检查证据与截图（不进入 Git）                   |
| `04_构建脚本` | 开发启动、构建、源码打包脚本                       |
| `05_项目文档` | 当前说明、规划、调研及历史审查记录                 |
| `06_构建产物` | 自动生成的运行文件（不进入 Git）                   |
| `07_发布成品` | 本地打包输出（不进入 Git），EXE 通过 Releases 分发 |
| `08_演示体验` | 原创虚构样例和演示步骤                             |
| `09_源码交付` | 本地生成的源码包（不进入 Git）                     |

EXE 使用 `%APPDATA%\FileCanvas`，开发版使用 `%APPDATA%\FileCanvas-Development`，两者的画布项目和 AI 配置不会自动同步。详细的更新内容见 [CHANGELOG](CHANGELOG.md)。
