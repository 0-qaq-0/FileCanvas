# FileCanvas 0.4.0 EXE 使用与交付说明

交付日期：2026-10-18。本轮将现有 0.4.0 源码打包为 Windows x64 免安装程序，方便直接试用；应用功能与 0.4.0 源码版一致。

## 成品与启动

- 程序：[FileCanvas-0.4.0-Windows-x64.exe](../07_发布成品/FileCanvas-0.4.0-Windows-x64.exe)。单个 EXE 即可运行，无需 Node.js 或源码目录。
- 快捷方式：[打开演示软件.cmd](../08_演示体验/打开演示软件.cmd)，已改为指向 0.4.0。
- 随包资料：`07_发布成品/0.4.0_发布资料`；成品摘要：`07_发布成品/SHA256SUMS-0.4.0.txt`。

双击 EXE 后，首次可点 **先用 20 个示例文件试一遍**。程序每次生成全新的虚构样例副本，可以实际整理和恢复，不需要准备个人文件。

当前程序未做代码签名，Windows 可能显示来源提示；本轮未配置安装器或自动更新。当前仅提供 Windows x64 成品。

## 第一次完整试用

1. 打开内置样例，单击文件夹展开，查看文件卡片和图片、文本预览。
2. 点 **分类草案 → 采用草案到画布**，或自己拖动、改名、新建文件夹。此时目录结构仍未写入磁盘。
3. 点 **检查并应用 → 结构对照**，确认原路径和目标路径。
4. 点 **应用到本地文件**。看到“已应用并核验”后，目录里的文件已实际移动。
5. 点 **更多工具 → 恢复上次文件移动 → 恢复文件原位置**，检查样例恢复。完成整理后，画布附近也会显示恢复入口。

`Ctrl+Z` 用于撤销画布计划；磁盘路径恢复需要使用第 5 步的入口。恢复的是最近一次整理涉及的路径，不提供文件正文的历史版本备份。

自己的目录建议先用少量副本试用。当前范围是同一授权根目录内、本地支持硬链接的文件系统，建议 NTFS；每次最多移动 100 个文件。不支持跨盘、网络共享或符号链接/目录联接内的整理。完整限制见 [源码版说明](0.4.0源码版使用与交付说明.md)。

## AI 与项目数据

基本文件整理不依赖 AI。需要 AI 解释文件、推荐位置或继续追问时，在 **AI 助手** 配置自己的服务、模型和密钥，并允许当前项目发送资料。相关文本会发送到配置的模型服务；外部服务可能收费。

目前主要使用文本、代码和文件元信息；PDF、Office、音视频尚未提取正文。本轮 EXE 验收没有调用真实模型服务，不能据此承诺回答质量或费用。

EXE 的画布、项目和操作记录默认在 `%APPDATA%\FileCanvas`；开发启动使用 `%APPDATA%\FileCanvas-Development`。两者的项目和 AI 配置不会自动同步，第一次打开 EXE 显示欢迎页属于正常情况。“免安装”指无需安装步骤，运行数据仍会写入应用数据目录。

恢复依赖软件的操作记录和执行期间的恢复区；如有未完成任务，请保留这些目录。部分 Store/MSIX 启动环境会重定向 AppData，可通过软件内查看目录入口定位实际位置。
