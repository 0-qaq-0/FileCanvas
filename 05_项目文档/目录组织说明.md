# 项目目录与迁移说明

0.4.0 补充：`09_源码交付` 保存源码目录、ZIP 和摘要；`04_构建脚本/package-source.mjs` 负责按白名单打包。当前功能与限制见 [0.4.0 说明](0.4.0源码版使用与交付说明.md)。下文验收数量记录的是目录迁移当时的版本。

原先位于 `D:\ai\a_小红书接单` 的项目文件现已整体迁移到其子文件夹 `FileCanvas`。原位置只保留这个项目文件夹，便于以后放置其他项目。

## 源文件与生成文件

- `01_源码/src`：前端界面、领域模型和样式。
- `01_源码/electron`：桌面主进程、IPC、文件读取、AI 索引、受控磁盘整理和项目存储。`disk-operations.ts` 管理实际移动及撤销，`flow-demo.ts` 创建六文件开发样例。
- `01_源码/assets`：原创应用图标。
- `02_测试/单元测试`：领域与文件系统测试。
- `02_测试/交互测试`：实际 Electron 鼠标、键盘与持久化验收。
- `02_测试/启动检查`：开发模式、关闭握手、打包目录和便携包的检查脚本。
- `03_测试结果`：JSON 证据和截图；重新测试会更新同名结果。
- `04_构建脚本`：通过根目录 npm 命令执行，保持当前工作目录为项目根目录。
- `05_项目文档`：用户说明、验收记录及本说明。
- `06_构建产物/renderer`、`06_构建产物/electron`：编译生成，不是源码。
- `07_发布成品`：便携 EXE 和 `win-unpacked` 完整目录。
- `08_演示体验`：20 个原创真实示例文件、清单、演示指南与打开程序入口；0.1.0 EXE 归档在 `07_发布成品/历史版本/0.1.0`。

项目根目录的配置文件负责串联上述文件夹。不要只移动或复制 `01_源码` 后期待 npm 能独立运行；继续开发需保留根目录配置、构建脚本及测试。

## Git 和数据

完整 `.git` 历史随项目移动，代码路径变化会作为一个单独的目录整理提交保存。`node_modules`、构建产物、发布成品和测试结果保持不纳入 Git；需要备份可执行程序时，请另外保存 `07_发布成品`。

已发布软件的个人项目保存在 `%APPDATA%\FileCanvas\projects`；当前开发版使用独立的 `%APPDATA%\FileCanvas-Development`，其中 `projects` 保存项目，`operations` 保存磁盘整理记录，`flow-demos` 保存六文件试用副本。它们没有随源码目录迁移。系统临时目录内的专用测试样本也不移动；测试结果记录其实际位置，方便核对。

新画布组件是 `01_源码/src/components/ExpandedCanvas.tsx`；合并的文件解释与预览是 `FileInspector.tsx`；展开布局和建议采用逻辑分别在 `src/domain/canvas-layout.ts`、`file-advice.ts`。

已有 EXE 在迁移后仍可直接运行；迁移后的源码已调整构建、测试、资源和输出路径，后续构建会写入对应的新文件夹。
